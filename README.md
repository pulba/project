| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `bun install`             | Installs dependencies                            |
| `bun dev`                 | Starts local dev server at `localhost:4321`      |
| `bun prod`                | Build your production site to `./dist/`          |
| `bun wpreview`            | Preview                                        |
| `bun wdeploy`             | Deploying                                        |
